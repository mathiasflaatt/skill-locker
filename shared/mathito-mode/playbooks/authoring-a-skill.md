### Authoring or changing a skill

1. Load **skill-locker** and pull first. Load **writing-for-agents**.
2. Keep only prose that changes a decision. Delegate to other skills by name or path, do not restate them.
3. Validate: frontmatter has `name` and `description`, referenced files exist, named skills exist.
4. Copied from another author: keep its `LICENSE`, add a row to `CREDITS.md`.
5. Push with skill-locker. `status` is clean and level with `origin`.

**Reply:** what the skill does, key choices, validation.
