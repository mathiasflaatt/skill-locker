Move session tokens into httpOnly cookies

Today any script on the page can read the session token. After this change only the browser can.

Q1. Should the mobile app move to cookies too?

Decides whether step 3 can drop the bearer path entirely.

Why not keep the token and add a CSP?

misses
first-party XSS

A CSP narrows the attack but a single bug in our own scripts still reads the token. The cookie removes the token from script reach entirely.

TrapSameSite=Lax still sends the cookie on top-level GET navigations, so every GET must stay side-effect free.

Steps

  1. Add cookie middleware beside bearer authBoth accepted, so old clients keep working.
  2. Login sets the cookieThe body still carries the token for one release.
  3. Drop localStorage and the bearer pathAfter one release cycle.
